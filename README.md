### A little context

I started out simply wanting to build things. Over time that turned into a fascination with what happens underneath the interface — how applications communicate, how databases behave, how systems scale, and what happens when something inevitably breaks.

These days, system design is probably the part of software engineering I enjoy the most. I like taking a messy problem, breaking it into smaller pieces, and figuring out how those pieces should work together.

My usual stack is Next.js, Node.js, TypeScript, and MySQL, but I'm not particularly attached to a specific stack. The problem usually determines the tools.
